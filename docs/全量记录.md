## 二、本轮代码改动

`app/views/chat.js` · 输入法焦点，三层：

| 层 | 位置 | 做法 | 为什么 |
|---|---|---|---|
| 1 | 第 242 行 | `sendBtn.addEventListener('mousedown', e => e.preventDefault())` | 按下按钮时焦点从 input 转到 button → input 失焦 → Android 立刻收软键盘。**只能拦 mousedown**：在 touchstart 上 preventDefault 会把 click 一起吞掉，消息发不出去 |
| 2 | 第 372–377 行 | `send()` 包一层 `doSend()`，发完 `setTimeout(() => ipt.focus(), 0)` | 回车发送、以及部分机型 IME 提交后会自己失焦，仍需兜底。条件是 `document.body.contains(ipt)`——用户发完立刻返回时视图已销毁，focus 游离节点没意义 |
| 3 | 第 588–592 行 | keydown 里先 `e.preventDefault()` 再 `send()` | Android 输入法把回车当成「完成」，提交后自动收键盘 |

`doSend` 里有 6 处提前 return，所以用包装层，不在每个出口写一遍。

## 八、第二轮：补漏测 → 抓到真 bug → 打包 0.4.2

修完全量第一轮后，把第一轮承认的漏测补上（`tests/chat.js` 50 → 53）。断言一写就红了，而且是**代码的错，不是测试的错**。

### 1）怎么让它测得出来

`jsdom` 里 `focus()` 一个脱离文档的节点**根本不生效**（`activeElement` 不变），所以「焦点在不在它身上」这路断言无效。改成给 `ipt.focus` 挂一个计数器，直接数**有没有被叫过**：

```js
const iptGone = q('#chatIpt');
let focusCalls = 0;
iptGone.focus = function () { focusCalls++; };   /* 只数次数，不真的 focus */
sendBtn().click();
w.Nav.back(false);          /* 同步离开，不等 setTimeout(0) 落地 */
await wait(200);
ok('发完立刻返回，回焦没有打到已销毁的输入框', focusCalls === 0);
```

第一次跑：`focusCalls === 1`，红。

### 2）插桩定位

把 `document.body.contains` 打桩，打出每次调用的返回值和当时的连接状态：

```
CLICK 前 connected=true
BODY.CONTAINS ret=true connected=true tag=INPUT   ← 只在 click 期间求值一次
CLICK 后 connected=true
FOCUS CALLED connected=false                      ← 执行时节点已脱离文档
```

### 3）根因

原写法把 `contains` 判断放在 `setTimeout` **外面**：

```js
if (document.body.contains(ipt)) {                 /* 注册那一刻求值 */
  setTimeout(function () { ipt.focus(); }, 0);     /* 下一个宏任务才执行 */
}
```

判断发生在「注册那一刻」（输入框还在页面上 → 放行），`focus` 发生在「下一个宏任务」。用户点完发送立刻按返回，视图在这两者之间被 `$app.innerHTML = ''` 拆掉，于是对着游离节点执行 `focus()`。**Android WebView 上的表现是「已经退出会话了，键盘自己跳出来」。**

这是 0.4.2 里最值钱的一个发现：它在 0.4.1 就存在，但只靠读代码看不出来。

### 4）修复

判断挪进 `setTimeout` 内部：

```js
function send() {
  doSend();
  setTimeout(function () {
    if (!document.body.contains(ipt)) return;   /* 视图已销毁，别去碰它 */
    try { ipt.focus(); } catch (e) { }
  }, 0);
}
```

### 5）反证

把内层判断挪回外层（复原旧写法）→ 「发完立刻返回，回焦没打到已销毁的输入框」**精确红 1 条**；还原 → 53 项全绿。
